Every skill is `m.skills.<name>`: `m.skills.woodcutting`, `m.skills.cooking`, `m.skills.beastcrafting`. Each has its live level and XP; the supported ones also have actions. This guide goes from picking a recipe to gathering, then crafting. The calls are in the [reference](/reference/skills/).

## Which skills work

| | Skills | A recipe is |
| --- | --- | --- |
| **Gathering** | Woodcutting, Mining, Fishing | A tree, a rock, a fishing spot |
| **Crafting** | Smithing, Cooking, Firemaking, Crafting, Fletching, Runecrafting, Herblore, Beastcrafting | Something to make |
| **Not yet** | Farming, Thieving, Agility, Astrology, Ranching, Hunting | `start` and `act` reject them with `UNSUPPORTED` |

Combat skills (Attack, Strength, Defence, Hitpoints, Ranged, Magic, Prayer, Slayer) level up through [combat](/guides/combat/). Every skill, supported or not, has `level`, `xp` and `xpToNext`. The [roadmap](/roadmap/) says what's coming next.

## Pick a recipe

Recipes are typed ids, one map per skill: `WoodcuttingRecipes.NormalTree`, `MiningRecipes.Stone`, `FishingRecipes.ShallowPools`, `CookingRecipes.Shrimp`. VS Code lists them as you type, and the [id search](/reference/ids/) finds them by name. Melvor 2's ids aren't Melvor 1's, so search rather than guess.

## What's running, and stopping

`m.skills.<name>.active` is true while that skill is the character's action, and `current` is the recipe. `m.state.active` lists everything that's running. To stop it all:

<Snippet file="site/snippets/guides/skills.ts" region="stop" />

<Aside type="tip" title="Switching in real time">
In real time, changing what the character does is limited to once per second. `start()` waits that out by itself, so back-to-back `start()` calls on different skills take about a second each. Starting what's already running is free and doesn't count.
</Aside>

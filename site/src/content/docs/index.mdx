## What your scripts can do

<CardGrid>
  <Card title="Gathering and crafting" icon="setting">
    Woodcutting, Mining and Fishing, plus Smithing, Cooking, Firemaking, Crafting, Fletching, Runecrafting, Herblore and Beastcrafting.
  </Card>
  <Card title="Two ways to play" icon="random">
    **Real time**: start an action and the game repeats it, as if you'd clicked. **Scripted Mode**: every action happens the moment you ask, then a cooldown.
  </Card>
  <Card title="Combat" icon="star">
    Fight any enemy in an area, eat when you're hurt, leave when you're done. Combat runs in real time for now.
  </Card>
  <Card title="Live state and events" icon="rocket">

## Fair by design

Scripts play by the game's rules, not around them. Every level requirement is checked, and so are the materials a recipe needs. In real time the game decides how fast things happen, and a script can switch what it's doing at most once a second. In Scripted Mode each action waits its normal time divided by a speed you choose. Scripted actions never show up in the game's online "players training this action" counter, so other players' numbers stay honest. [How it works](/concepts/how-it-works/) explains the rules.

It's a programming game in the spirit of Screeps, Bitburner and Adventure Land, inside an idle game you might already play. Everything stays on your PC: the mod only accepts connections from it.

## Before you start

<ul class="req-strip">
  <li><strong>Windows + Steam</strong>The desktop game, from Steam.</li>
  <li><strong>Game 0.11.6-alpha</strong>The version this release was built and tested on.</li>
  <li><strong>Bun</strong>Runs your scripts. VS Code is recommended.</li>
  <li><strong>Early access</strong>No official mod API yet.</li>
</ul>

<Aside type="caution" title="Game updates can break it">
Melvor Idle 2 is in early access and has no official mod support yet. The mod reaches into the game's own code, so a game update can stop it working until the mod catches up. If the game starts misbehaving, delete `override.cfg` from the game folder and the game runs exactly as before.
</Aside>
